# 01. 매출 성과 대시보드

BigQuery 원본 데이터를 조회하여 연간/일간/판매상품 성과를 시각화하는 Streamlit 대시보드.

## 데이터 소스

| 용도 | 테이블 | 비고 |
|------|--------|------|
| 매출 원본 | `HANABQ.ZTIF9001` | 하나DB에서 매일 full-refresh |
| 이벤트 원본 | `HANABQ.ZTIF9009` | 무료 이벤트 참여/전환 |
| 교재 순위 | `lab_asia.BSM_KWD` | 키워드별 서점 순위 |
| GA 방문자/성과 | `DASHBOARD.GA4_DAY_TRAFFIC` / `GA4_DAY_PERFORM` | 잡이 매일 적재 |

## 탭 구성

### 1. 연간 성과
- 월별 매출 테이블 (연도별 비교, KPI 달성률, 전년 동기 대비 성장률)
- 월별 실매출 추이 라인 차트 + 전년 동월 대비 등락 막대
- KPI: 전년 동기 × (1 + 목표성장률%)

### 2. 일간 분석
- 상단 KPI 카드: KPI / 실매출 / 달성률 / 전년 동월 동요일 대비 성장률
- 주차별 일별 테이블: 목표매출 / 실매출 / 실매출인원 / 달성률 / 전년(요일동기) / 성장률 / 특이사항
- 특이사항 입력: 날짜 선택 → 텍스트 입력 → 저장 (세션 유지)
- 일별 누적 매출 라인 차트 (KPI / 올해 / 전년 요일동기)

### 3. 판매상품 분석
- 카테고리별 실적 테이블 (올해/전년 매출·건수·비중·증감)
- 카테고리별 매출·건수 막대 차트 (이중축)
- 카테고리별 매출비중 도넛 차트 (올해/전년 비교)

### 4. 무료 이벤트 효율
- 이벤트코드 입력 → 월별 참여자수/신규회원 전환수/이벤트 연계 매출 테이블
- 참여자 연령/성별 분포

### 5. 자타사 교재 순위
- 키워드 선택 + 기준일 선택
- 교보문고 TOP 10 + YES24 교차 순위 + 판매지수 + 변동
- 자사(해커스) 10위 밖이면 하단에 별도 강조

### 6. GA 성과
- 소스/매체별 기준일자 기준 + 이번달 누적 패널 (세션/매출전환/매출액/가입전환/증감)
- 연간 페이지 방문자수 테이블 + 라인 차트

## 매출 집계 기준

- 매출 발생일: `INTEG_RDATE` (통합 등록일)
- 순매출: `PAY_STATE='결제'` → +LSN_AMT, `PAY_STATE='환불'` → -LSN_AMT
- 공통 필터: `SPECIAL='00'`
- SUITE: 10=교재, 20=강의, 30=배송

## 사이드바 조건

- 사업부 (BSARK)
- 조회항목 LEVEL 1~4 (캐스케이딩 드릴다운)
- 기준일 / 비교 연도
- KPI 설정 (목표 성장률)
- 무료 이벤트 코드
- 검색어 트렌드 (주제어+하위검색어)
