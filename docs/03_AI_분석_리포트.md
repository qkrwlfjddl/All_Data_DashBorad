# 03. AI 분석 리포트 (Vertex AI / Gemini)

대시보드의 전체 데이터(매출, GA, 교재순위, 이벤트, 트렌드)를 Vertex AI에 넘겨
자동으로 복합 분석 리포트를 생성하고, 담당자가 검토 의견을 달 수 있는 구조.

## 구조

```
대시보드 데이터 (매출/GA/이벤트/교재/트렌드)
        │  요약 프롬프트로 정리
        ▼
Vertex AI (Gemini 2.5 Flash)
        │  8개 섹션으로 구조화된 분석 반환
        ▼
AI 분석 리포트 (각 섹션별 인사이트)
        │
        ▼  담당자가 검토 의견 입력
담당자 검토 의견 (text_area, 세션 저장)
```

## 8개 분석 섹션

| 섹션 | 분석 내용 |
|------|-----------|
| 종합 요약 | 전체 KPI 달성률, 매출 추이, 하이라이트 |
| 매출 증가 항목 — 견인 요인 복합 분석 | 매출 상승 카테고리 + GA + 교재순위 교차 |
| 매출 감소 항목 — 하락 요인 복합 분석 | KPI 미달 카테고리 + 원인 분석 |
| 검색 트래픽 × 교재순위 상관 분석 | 네이버 트렌드 + 교재 판매지수 |
| GA 캠페인 효율 × 매출 기여 분석 | 소스/매체별 전환율, 매출 기여 |
| 네이버 SA 노출 모니터링 | SA 관련 GA 소스 노출/경쟁 분석 |
| 무료 이벤트 → 유료 전환 분석 | 이벤트 참여 → 매출 연계 전환율 |
| Next Action 제안 | 우선순위별 액션 아이템 3~5개 |

## 사전 조건

### Vertex AI API 활성화
- GCP 콘솔 → "Vertex AI API" 검색 → 사용 설정

### 인증
- Cloud Run 배포 시: 서비스 계정에 `roles/aiplatform.user` 권한
- 로컬 개발: `gcloud auth application-default login`

### 모델
- `gemini-2.5-flash` (빠르고 저렴, 긴 컨텍스트)
- 1회 분석 비용: 약 $0.001 (거의 무료)

## 사용법

1. 사이드바에서 조건 설정 → "대시보드 적용" 클릭
2. "AI 분석 리포트" 탭으로 이동
3. "🤖 AI 자동 생성 완료" 버튼 클릭
4. 30초~1분 후 8개 섹션 분석 결과 표시
5. 각 섹션 옆 "담당자 검토 의견" 입력란에 의견 작성
6. 하단 다운로드 버튼으로 리포트+의견 텍스트 파일 저장

## AI 프롬프트 특성

- 각 섹션 5~8문장, 마침표 뒤 줄바꿈
- 마크다운 표 미사용 (본문에 수치 직접 기재)
- 이모지(📈📉🎯✅⚠️)로 중요 수치 강조
- 데이터 없는 섹션은 "분석 제한" 명시

## 리포트 요약 카드

AI 생성 전에도 표시되는 상단 요약:
- 월 누적 매출 (KPI 대비)
- 전일 매출
- GA 전환 성과 (전환건수/매출/가입전환)
- 자사 교재 최상위 순위
