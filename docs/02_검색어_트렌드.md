# 02. 검색어 트렌드 (네이버 데이터랩 API)

네이버 검색어 트렌드 API를 연동하여, 대시보드 안에서 키워드별 검색량 추이를 조회하고
자사 vs 경쟁사 비교를 시각화한다.

## 구조

```
사이드바 조건 입력 (주제어 + 하위검색어)
        │
        ▼  "대시보드 적용" 클릭
네이버 API (openapi.naver.com/v1/datalab/search)
        │
        ▼  JSON 응답 (기간별 상대 검색량 0~100)
검색 트렌드 탭에 라인 차트 + 표 표시
```

## API 키 설정

`app.py` 상단:
```python
NAVER_CLIENT_ID = "발급받은_ID"
NAVER_CLIENT_SECRET = "발급받은_SECRET"
```

### 발급 방법
1. https://developers.naver.com 접속 → 네이버 로그인
2. Application → Application 등록
3. 이름: 아무거나 (예: "매출대시보드")
4. 사용 API: **데이터랩 (검색어트렌드)** 체크
5. 비로그인 오픈 API: WEB 설정 → `http://localhost:8501`
6. 등록 → Client ID / Secret 복사

### 주의사항
- 2026.07.31 이후 네이버 개발자센터 신규 등록 차단 (기존 등록은 2027.06.30까지 사용 가능)
- 이후 NAVER API HUB (NCP)로 이관 필요
- URL 변경(배포 시)은 등록 후에도 수정 가능

## 사용법

### 조회
1. 사이드바 "검색어 트렌드" 섹션에서:
   - 주제어1~3 + 하위 검색어 (콤마 구분)
   - 시작일/종료일
   - 단위 (월간/주간/일간)
2. "대시보드 적용" 클릭
3. "검색 트렌드" 탭에서 결과 확인

### 프리셋 저장
- 키워드 입력 후 "프리셋 이름" 입력 → "프리셋 저장" 클릭
- BigQuery `DASHBOARD.TREND_PRESETS` 테이블에 영구 저장
- 다음 접속 시 프리셋 드롭다운에서 선택만 하면 키워드 자동 채워짐
- 사업군(BSARK)별로 분리되어 각 팀이 자기 프리셋만 보임

## 데이터 설명

- 검색량은 **상대값** (조회기간 내 최대 검색량 = 100)
- 절대 검색 횟수는 네이버가 제공하지 않음
- 하루 API 호출 한도: 1,000건 (전 팀 공유해도 충분)

## 표시 항목

- 라인 차트: 키워드별 검색량 추이
- 표: 기간 × 키워드별 수치 + 자사 대비 증감(vs 자사 컬럼)
